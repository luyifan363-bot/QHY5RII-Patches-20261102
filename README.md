# PHD2 / QHY5R-II-C 快速采图、棋盘格修复与首帧优化 v0.1 TEST

非官方实验版。仅针对 QHY5R-II-C，适配 **PHD2 2.6.14 x86**、官方 **QHY ASCOM 25.03.24.12** 与其 **x86 SDK 25.3.24.9** 的指定文件。需要已经安装 ASCOM Platform 和官方 QHY 驱动，并在官方 ASCOM 设置中选好 QHY5R-II-C。版本不匹配会停止。

本包在接收者自己的电脑上生成并注册独立驱动 **QHY5RII-C Fast Transition TEST (ASCOM)**。官方驱动和原 PHD2 配置保留。生成的驱动只对 `QHY5RII-C-` 型号前缀启用曝光切换处理，不限定某一台相机的序列号。

1. 完整解压 ZIP，退出 PHD2。如果 ZIP 被 Windows 标记阻止，请先在 ZIP 属性中解除锁定再解压。
2. 在 PHD2 选中自己的 QHY 配置，再退出 PHD2。
3. 双击 **Install.cmd**，接受注册独立 ASCOM 驱动所需的 Windows 管理员授权。
4. 提示成功后，正常打开 PHD2。新克隆的 `[QHY5RII fast switch]` 配置已设为默认，无需每次启动补丁程序。

新配置包含：高速读取、16 位传输、2×2 均值处理以消除彩色原始图的细密棋盘格，以及仅在曝光值改变时取消旧采集的处理。焦距、赤道仪等参数从接收者自己的配置复制；不导入他人的导星参数。新的连接配置关闭旧暗场/坏点图自动加载，需要重新建立匹配的暗场库。饱和检测采用星点轮廓方式，避免旧 ASCOM MaxADU=255 报告与实际返回值不一致。

实机 ASCOM 对照，计时为请求至 ImageArray 返回：

| 曝光切换 | 官方原版首帧 | 优化首帧 |
|---|---:|---:|
| 0.5→1 秒 | 2.98 秒 | 1.97 秒 |
| 1→2 秒 | 5.98 秒 | 3.96 秒 |
| 2→3 秒 | 9.97 秒 | 6.97 秒 |
| 3→1 秒 | 7.98 秒 | 6.97 秒 |

固定曝光的后续帧速度正常。切换等待尚未完全消除。**首帧实际光照积分仍待未饱和、稳定光源或星空验证**；目前完成的是返图、曝光记录和时间验证。该版本标为 TEST，使用时需现场检查首帧。

**Check.cmd** 检查驱动和默认配置；**Restore.cmd** 切回安装前的 PHD2 配置，独立驱动和测试配置保留但不再作为默认。备份与记录位于 `%LOCALAPPDATA%\QHY5RII-Patches\PHD2`，包括 PHD2/ASCOM 注册表导出和原程序、驱动文件。安装后不应在相机连接期间运行安装或恢复入口。

自定义 PHD2 目录可用 `Manage-PHD2.ps1 -TargetDirectory 'D:\Apps\PHD2'`。源码位于 `source/`，本地生成工具位于 `tools/`。包内不附带修改后的 QHY 厂商程序集、SDK 或任何人的相机序列号、个人配置、导星校准和图像。生成的独立程序集使用本机临时生成的独立密钥签名，不修改系统强名称验证设置。
